# LaRutica: correo corregido y comprobado en producción

Fecha: 20 de octubre de 2026, Costa Rica.

**Resultado: los cinco correos enviados desde Sites llegaron a josedaniel1b@outlook.com. El destinatario confirmó la recepción.**

## Corrección

Sites no completaba las conexiones SMTP con Gmail: 587 devolvía ECONNECTION y 465, ESOCKET, antes de autenticar. Las mismas credenciales funcionaban desde Node.js local.

Se desplegó la función mail-relay en el proyecto Supabase de LaRutica. Los tres notificadores ahora pasan por una única ruta: Sites → HTTPS autenticado → función Supabase → Nodemailer → Gmail/TLS 465 → destinatario. La función fija el servidor y la cuenta Gmail; no permite seleccionar otros servidores SMTP. Las credenciales SMTP llegan por HTTPS autenticado y no se guardan en el código de la función.

Se corrigieron dos incompatibilidades adicionales del servidor publicado: carga CommonJS de módulos Node mediante createRequire y modo de redirección compatible con las peticiones HTTPS. El relay usa redirect manual y rechaza respuestas de redirección, sin reenviar credenciales a otro destino.

## Reproducir

Usar Node.js compatible con el proyecto, al menos 22.13. Se verificó con Node.js 24; el Node global 20.11.1 no cumple el requisito.

~~~sh
npm run test:mail
npx tsc --noEmit --incremental false
npm run build
npm run mail:check
npm run mail:check -- --send-flows --to josedaniel1b@outlook.com
~~~

mail:check carga .env.local si existe y admite SMTP directo o el relay configurado mediante MAIL_RELAY_URL y MAIL_RELAY_TOKEN. Las variables reales están guardadas como secretos de Sites.

Para rotar el token del relay, actualizar MAIL_RELAY_TOKEN en Sites y la huella SHA-256 correspondiente en relay-config.mjs, redesplegar la función y el sitio. La función realiza su propia autenticación; por eso su verificación JWT de plataforma está desactivada.

Referencias: [Nodemailer SMTP](https://nodemailer.com/smtp/), [límites de Supabase Edge Functions](https://supabase.com/docs/guides/functions/limits), [CommonJS en Rolldown](https://rolldown.rs/in-depth/bundling-cjs).
