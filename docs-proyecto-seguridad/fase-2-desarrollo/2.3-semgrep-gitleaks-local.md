## Decisiones tomadas

- Reglas locales explícitas y métricas desactivadas; sin depender de una cuenta o reglas remotas cambiantes.

- Sin allowlists para maquillar el resultado. Los posibles falsos positivos se documentan para revisión.

4. El propietario del relay debe confirmar que el token tiene entropía adecuada y no se expuso (el hash SHA-256 es público y un token débil sería atacable offline). Bloquea marcar Listo; registrar en 7.5.
